# K2D

K2D by Cadson Demak, redistributed unmodified under SIL Open Font License 1.1 (see OFL.txt).

Downloaded 2026-11-11 from the official Google Fonts CSS2 API and fonts.gstatic.com, K2D v13, normal weights 400/500/600/700, Latin and Vietnamese WOFF2 subsets. No additional family. Sources: https://fonts.google.com/specimen/K2D and https://github.com/google/fonts/tree/main/ofl/k2d.

Self-hosted to avoid third-party font requests and render-blocking remote stylesheets. Only the 500-weight Latin and Vietnamese subsets used by hero/recipient headings are preloaded. Weights 400/600/700 load on demand with `font-display: swap`; the additional preload experiment did not improve measured loading time.
